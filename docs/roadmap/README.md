# 开发路线

## 当前阶段

- Bybit 和 Binance 公开行情检查。
- 私有余额只读检查。
- 已收盘 K 线上的 EMA/RSI 信号。
- 包含手续费、滑点及浮动盈亏的异步回测，历史数据分页下载和指纹保存。
- Vue / FastAPI 本地平台，支持自选、策略管理、持仓、订单及事件记录；原研究仪表盘保留。
- 可恢复的模拟交易引擎，暂停停止新开仓并继续保护持仓。
- 参数批次对比、Optuna 自动选参、独立区间及分窗口验证。
- 权益曲线按需增量加载，历史明细可预览、校验后手动归档。

## 后续阶段

1. PostgreSQL / Docker 实际环境验证与长期运行观察。
2. Testnet 下单、合约规则、订单状态、持仓和交易所止损保护。
3. 真实成交与仓位对账、限频、断线恢复及故障演练。
4. 更完整的资金费率、保证金和强平模型，以及账户总风险控制。
5. 完成上述检查后，再单独评审主网部署。
