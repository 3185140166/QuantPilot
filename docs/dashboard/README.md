# 量化研究工作台

```powershell
python -m pip install -e .
streamlit run quantpilot/dashboard.py
```

如需本地 HTTP 代理，在启动页面的同一 PowerShell 窗口设置，端口以代理软件实际配置为准：

```powershell
$env:HTTP_PROXY = "http://127.0.0.1:7790"
$env:HTTPS_PROXY = "http://127.0.0.1:7790"
streamlit run quantpilot/dashboard.py
```

## 功能

- 行情总览：选择交易所、币种、周期和样本数量；查看 K 线、均线、成交量；支持横向缩放和平移。
- 策略与回测：调整资金、固定交易数量、手续费和滑点，查看权益与回撤。
- 回测成交记录：查看模拟成交并导出 CSV。
- 数据中心：查看行情和技术指标并导出 CSV。

行情缓存 60 秒，页面不自动轮询；点击刷新重新请求。缓存区分交易所、主网或测试网、品类及行情参数。回测单独缓存，切换图表开关不会重复计算相同回测。

## 计算口径

时间统一为 UTC。最新一根可能未收盘的 K 线被移除；样本高低价不等于 24 小时高低价。

EMA 20/60 交叉配合 RSI 14 过滤，信号仅使用当前及过去数据，下一根开盘模拟成交。RSI 预热期保留缺失值；成熟的持续上涨、持续下跌、横盘序列分别对应 100、0、50。

权益曲线按每根收盘价盯市，包含持仓浮动盈亏；样本末尾强制平仓，终点包含手续费和滑点。未模拟资金费率、杠杆保证金、强平及最小交易量。默认指标需要至少 63 根 K 线。完整版平台额外支持参数化模板、历史日期区间及模拟止损止盈。

页面只访问公开行情，不提供真实下单控件。
