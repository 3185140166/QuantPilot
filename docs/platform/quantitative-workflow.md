# 量化策略五步流程

本轮新增的是固定规则的研究和执行流程，不是自动寻找盈利策略。已有自动交易配置保持原值；动态筛选、研究准入限制、监测暂停默认关闭，均在“交易助手 → 策略设置”保存后生效。研究、扫描和应用参数都不会自动启动交易。

## 1. 合约筛选与适配

先保存最多10个USDT合约作为观察池。动态筛选支持成交额优先或固定“趋势与波动比值”排序，并设置候选前N个、成交额下限、ATR上限。成交额取最近24根已收盘K线的收盘价乘成交量中位数，属于估算；趋势评分在动量方向与均线差一致时使用均线差绝对值除以ATR波动率，不是胜率、预测收益或拟合权重。

启用筛选后，同时检查固定共享预算与止损风险是否满足合约最小订单。实际下单仍需扣除账户已有占用，并执行盘口、报价有效期、相关性和组合风控检查。候选排名先于入场信号：入选可以继续等待，不会追单；排名退出不触发平仓。手工订单与持仓继续按原有归属规则处理。

“扫描已保存的币种”显示候选排名、排除原因、预算适配和验证关联状态。“已关联验证”只表示参数来源，不表示通过研究准入或盈利证明。

## 2. 因子研究

保存筛选、策略和风险规则后，在“研究验证”创建多币共享预算研究。详情同时展示原单币时间序列诊断与新的多币横截面诊断。

横截面诊断比较同一时刻不同币种的因子排名与后续4根K线收益，至少3个币种、30个不重叠观察期才显示汇总。高组减低组是未扣成本的毛收益，不是可交易收益。方向和评分规则不会因为诊断结果自动改变；不要反复根据验证结果调参。

## 3. 动态筛选组合回放

组合研究在每个历史时点只使用当时已收盘数据筛选，再按下一根成交假设处理入场。筛选与交易助手共用同一函数；风险仓位算法也共用。详情提供逐时候选记录（最多展示前500次，整体收益仍覆盖完整回放），包括被筛选跳过的信号数。

成交、资金费、保证金与强平仍沿用原有研究模型。固定当前观察池存在幸存者偏差，尚未还原历史上市/退市池；回放不是订单簿级模拟。测试网数据和成交不能直接视为主网表现。

## 4. 稳定性与研究准入

组合研究增加邻近参数检查和双倍手续费/滑点压力回放。邻近参数仅在研究段检查，后续验证继承该证据，不重新按验证结果选择参数。邻近规则使用共同预热区间。创建“验证”时，必须选研究结束之后的独立区间，规则和筛选保持冻结。

准入检查包含：关联后续验证、币种池/预算/筛选/风险/市价模型一致、成交样本数、成本后正收益、预算口径回撤上限、包含资金费且无强平近似、价格和标记价格审计、成本压力及研究段邻近参数。普通资金费接口覆盖说明作为限制保留；实际缺失/异常警告会使准入失败。

最低成交数默认20笔，是可配置的流程下限，不代表统计充分。缺失检查、旧任务没有新报告均视为未通过。报告可以预览；启用“未通过验证禁止应用和启动”后，应用与启动均由后端检查，执行进程也会复核。建议在研究前确定所有设置；应用后修改配置需要重新核对或研究验证。没有开启限制时，报告仅为诊断。

## 5. 运行监测

核对并应用验证参数后仍保持暂停。先在测试网自行启动，观察“策略证据与运行监测”。监测窗口为最近100次开仓，仅统计与当前完整配置匹配、已确认且已对账的本系统交易，按平仓时间计算连续亏损。展示净收益、费用、资金费以及相对计划价格的不利成交偏差，并对照配置费用假设和关联验证收益；验证与运行区间不同，不能直接比较总收益。

启用监测暂停后，连续亏损达到配置门槛、足够样本的平均不利成交偏差超限，或实际开仓费率超过配置两倍，都会暂停本系统新开仓。不会因此强平、撤单或处理手工仓位，交易所已有保护继续保留。重新启动也会复核触发条件，不能简单点启动绕过；应检查原因并在允许修改配置的状态下处理。

本轮验收使用独立临时数据库与替代交易接口，没有启动真实账户交易，也没有修改账户模式。
# 从模拟策略进入交易助手

## 多周期与账户风险

小时方向使用有限窗口的归一化指数权重均线，固定取最近“慢EMA周期＋1”根完整小时K线。它不是无限历史EMA，目的是让历史长序列与运行时短窗口使用同样的方向计算，避免种子差异；页面图表的普通EMA数值可能不同。此规则需要通过研究验证后才考虑执行。

交易助手配置中的“填入15分钟研究起点”只填写未保存草稿，不保存、不下单：使用完整已收盘1小时EMA20/60方向过滤，15分钟模板决定入场，均线间距不足时等待。止损2%、止盈4%、单笔风险0.5%、组合风险1%、日亏损2%、回撤5%、最多2仓、2倍杠杆、现金保留20%；同时填入三窗口研究准入和运行监测。币种、预算、成本与其他过滤保持原值，需要用户核对。这个起点尚未经收益验证。

小时方向由15分钟数据聚合，仅包含四根完整已收盘K线。预热、缺失小时数据或中性方向会暂停入场；不使用未收盘小时的最终结果。开启时信号周期只能为15分钟，慢EMA不超过200；回测、模拟及交易助手共用信号代码。单币研究此时只创建一个多周期策略任务；关闭后可分别研究15分钟、1小时、4小时。

组合研究完成后选择“多窗口验证”，指定后续区间及2至5个窗口。所有窗口不重叠、参数固定，每个窗口独立重置资金；这是固定规则的连续样本外验证，不自动在每个窗口重新优化，也不把收益相加当作实盘收益。验证详情可查看整组完成状态与失败项。启用准入并将最低窗口数设为3时，应用和启动都会重新核查同组所有窗口，缺失、失败、参数不一致或某窗口未通过均阻止。

账户风险汇总包含本系统、手工／其他程序和未知来源持仓，以及外部开仓挂单名义金额。已知止损风险按入场价和成本估计，不是最坏损失；无止损持仓使风险合计不完整。外部仓位仍不会被系统接管。现金保留按固定预算计算，从交易所可用余额中扣除后参与回测和执行仓位计算，默认0保持旧行为。请以新鲜账户快照为准；账户级日亏损、回撤和开仓前检查仍执行。

策略管理中的“研究并用于交易助手”会进入助手的研究验证页，并预选该 Bybit 模拟策略。也可以直接在研究页的规则来源列表选择策略。

选择来源只用于研究，不修改助手配置，不启动交易，也不导入模拟持仓、现金或固定下单数量。提交时后端读取策略的最新规则并保存快照，使用助手已保存的预算、杠杆与成本参数分别研究三个周期；需要正数止损。原策略周期仅作参考。

选定研究结果后创建后续独立验证，完成后在“从验证回测应用研究参数”中预览并应用。默认只使用回测币种，预算与账户风控仍需核对。应用后助手保持暂停，由用户单独启动。

助手显示验证回测编号、来源策略名称及配置修改状态。来源策略后续修改或删除不改变已保存快照；修改助手参数后需重新验证。历史未记录来源策略的回测仍可正常使用。
